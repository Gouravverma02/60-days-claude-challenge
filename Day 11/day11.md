## Key Learnings

1. ATS prefers clear section headings.
2. Skills should be grouped into categories.
3. Keywords should appear naturally in projects and experience.
4. Action verbs improve recruiter readability.
5. Resume formatting affects ATS parsing accuracy.

## Challenge Reflection

One ATS improvement I discovered was that simply listing technologies is not enough. Organizing skills into categories and incorporating keywords into project descriptions significantly improves ATS relevance.
